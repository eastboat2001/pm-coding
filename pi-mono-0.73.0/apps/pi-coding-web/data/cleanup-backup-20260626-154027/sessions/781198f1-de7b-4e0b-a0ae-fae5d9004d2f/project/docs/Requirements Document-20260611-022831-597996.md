## 2. Background and Objectives

### 2.1 Background
The dashboard provides a high-level view of key yield metrics for various products. It is updated via automated scheduled scripts daily to allow QDM and yield teams to review performance without manual report preparation. It supports trend analysis, Pareto analysis of loss codes, and attribution by department.

### 2.2 Objectives
*   **Improve Yield:** Visualize trends to drive a steeper improvement curve.
*   **Cost Reduction:** Lower production costs by identifying and mitigating loss.
*   **Output Optimization:** Increase production output without significant additional investment.
*   **ROI:** Recover investment costs sooner through data-driven quality management.

### 2.3 Success Criteria
*   Business and data owners agree on metric definitions and source logic.
*   Users can identify the latest yield, output, and major defects from the primary screen.
*   Drill-down functionality correctly links yield trends to specific defect codes and departments.
*   Dashboard data matches approved source query results.

## 3. Page / Function Presentation

## 3.1 Finished Lot Performance Overview Trend
*   **Purpose:** Display finished yield trends and latest-week KPIs (Output, Yield, NSQM Loss).
*   **Header:** `QUALITY OPERATION CENTER - Weekly Finished Lot Performance Overview`.
*   **Main Chart:** A bar/line combo chart showing weekly performance (e.g., 202612 to 202621). Bars represent weekly values; lines show target/yield trends.
*   **Interaction:** Clicking a weekly bar updates the right-side detail panel and the defect analysis section below.
*   **Right Panel:** KPI cards for the selected week:
    *   Yield / Target (e.g., 96.83% vs 94.81%)
    *   Finished Count (e.g., 159 Lots)
    *   Output (NSQM/NSOM)
    *   Loss (NSQM/NSOM)

### 3.2 Loss Ratio By Defect Code
*   **Purpose:** Display top 10–20 defect loss ratios and their trends.
*   **Main Chart:** Ranked horizontal bar chart (Pareto style). Red bars = Total Loss Ratio; Blue bars = Core Loss Ratio.
*   **Right Panel (Drill-down):**
    *   **Trend Chart:** Weekly overview trend for the selected defect code (e.g., ED25).
    *   **Donut Chart:** Department attribution (e.g., Etching + AOI, Assembly, Material).
*   **Defect Codes:** Includes codes like ED25 (Short in inner layer), AP09 (Component tilting), GE01 (Scratches), etc.

## 6. Yield Calculation Logic

### 6.1 Finished Yield Definition
Finished Yield represents the percentage of units passing the full process. It is the product of individual process yields.

6.2 Formula
*   **Lot Product Yield:** `(PAOI Output/Input) * (E-test Output/Input) * (CCAOI Output/Input) * (Bump AOI Output/Input) * (FVI Output/Input)`
*   **Weekly Product Yield:** Product of each process's weekly aggregated shipped output/input ratio.
*   **Extension Rule:** If "Inline" or "Others" are approved, they are multiplied into the sequence.

### 6.3 Calculation Example
If process yields are: PAOI (99.4%), E-test (99.5%), CCAOI (99.29%), Bump (99.38%), FVI (99.17%), Inline (99.49%), Others (99.39%):
**GTY = 99.4% * 99.5% * 99.29% * 99.38% * 99.17% * 99.49% * 99.39%**
