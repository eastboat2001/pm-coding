# 个人备忘录日历

一个轻量级的纯静态网页日历应用，支持本地备忘录记录，无需后端服务器。

## 功能特性

- 📅 按月展示日历，每周从周一开始
- 📝 点击日期编辑备忘录（纯文本）
- 💾 数据本地持久化存储（LocalStorage）
- 🎯 年份快速跳转（当前年份 ±10年）
- 📍 "回到今天"快速定位功能
- 🎨 视觉标记：有内容的日期背景色变更，今天特殊高亮

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript（ES6+）
- 零框架依赖
- 浏览器原生 LocalStorage

## 使用说明

### 基本操作

1. **查看日历**：页面默认显示当前月份
2. **切换年月**：使用顶部下拉框选择年份和月份
3. **编辑备忘录**：点击任意日期格子，在弹窗中输入内容
4. **保存内容**：点击"💾 保存"按钮
5. **删除内容**：点击"🗑️ 删除"按钮清空该日期的备忘
6. **回到今天**：点击"📅 回到今天"按钮快速返回当前日期

### 数据存储

- 所有数据存储在浏览器的 LocalStorage 中
- 存储键格式：`memo_YYYY-MM-DD`（例如：`memo_2024-01-15`）
- 清除浏览器缓存会丢失数据
- 数据仅保留在当前浏览器，不同设备间不共享

## 已知假设与取舍

1. **无后端依赖**：本项目为纯静态应用，所有数据存储在用户本地浏览器
2. **PC 端优先**：主要针对桌面浏览器优化，未做移动端深度适配
