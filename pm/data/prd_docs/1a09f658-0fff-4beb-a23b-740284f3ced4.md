# PRD 文档模板（简洁版）

## 1. 文档信息

- **项目名称**：个人备忘录日历
- **需求名称**：纯静态网页日历备忘录需求规格说明

## 2. 需求背景

### 2.1 背景说明

用户需要一个轻量级的个人工具，能够在 PC 端浏览器上快速查看日期并记录每日备忘信息。为了保证隐私性和便捷性，该工具不依赖后端服务器，数据需存储在用户本地。

### 2.2 需求目标

- 提供一个无需安装、即开即用的纯静态日历页面。
- 实现备忘录的本地持久化存储（LocalStorage）。
- 优化视觉反馈，使用户能直观识别哪些日期已有记录。

## 3. 需求范围

### 3.1 本次范围

- **技术实现**：使用原生 HTML、CSS、JavaScript 开发（不使用 Vue/React 等框架）。
- **核心功能**：日历按月展示、年月快速跳转、点击日期弹出备忘录编辑框。
- **数据存储**：使用浏览器 LocalStorage 存储纯文本备忘内容。
- **视觉效果**：有内容的日期格子背景色变更、“今天”特殊高亮。

### 3.2 非本次范围

- 不涉及后端服务器及数据库集成。
- 不涉及移动端响应式适配（仅限 PC 端使用）。
- 不涉及多端数据同步或导出功能。
- 不支持任务清单（Todo List）的勾选模式，仅支持纯文本备注。

## 4. 用户与使用场景

### 4.1 目标用户

- PC 端办公用户。
- 需要简单、私密地记录每日工作/生活摘要的个人用户。

### 4.2 核心使用场景

1. **查看与导航**：用户打开网页，通过下拉框跳转到特定年份查看过往记录或未来计划。
2. **记录备忘**：用户点击某个日期，在弹出的模态框中输入详细备注并保存。
3. **快速复位**：用户在浏览其他月份后，点击“回到今天”按钮快速返回当前日期视图。

## 5. 功能需求

### 5.1 功能概述

系统实现一个以周一为起始的日历网格，支持通过 LocalStorage 读写纯文本备注，并提供年月跳转及“今天”高亮功能。

### 5.2 功能点明细

#### 功能点 1：日历核心展示

- **功能描述**：按月展示日期网格，每周从周一开始。
- **触发方式**：页面加载或切换年月。
- **处理逻辑**：根据当前选择的年月，计算当月天数及第一天相对于周一的偏移量，动态生成日历表格。
- **输入项**：系统日期、用户选择的年份/月份。
- **输出结果**：渲染 7 列多行的日历布局。

#### 功能点 2：备忘录编辑弹窗 (Modal)

- **功能描述**：点击日期格子弹出悬浮在页面中央的模态框。
- **触发方式**：点击任意日期格子。
- **处理逻辑**：根据点击的日期（如 `2023-10-27`）从 LocalStorage 读取数据并填充至多行文本框。
- **输入项**：点击的日期 ID。
- **输出结果**：展示包含多行文本区域的弹窗。

#### 功能点 3：数据持久化管理

- **功能描述**：支持备忘内容的保存与一键清空。
- **触发方式**：点击弹窗内的“保存”或“删除/清空”按钮。
- **处理逻辑**：
    - **保存**：以日期字符串为 Key，文本内容为 Value 存入 LocalStorage。
    - **删除**：移除 LocalStorage 中对应的 Key。
- **输出结果**：更新本地存储，并同步更新日历格子的背景色。

#### 功能点 4：快速导航与复位

- **功能描述**：通过下拉框跳转及“回到今天”按钮。
- **触发方式**：操作下拉菜单或点击按钮。
- **处理逻辑**：更新当前视图变量，重新渲染日历。年份下拉框范围为：当前年份 ±10 年。

## 6. 业务规则

- **周起始日**：每周的第一天固定为周一。
- **视觉标记规则**：
    - 若某日期在 LocalStorage 中存在非空 Value，该格子背景色需区别于普通格子。
    - “今天”需有特殊的视觉样式（如边框加粗或高亮色）。
- **存储规则**：数据仅保存在当前浏览器的 LocalStorage 中，清除浏览器缓存会导致数据丢失。

## 7. 页面 / 交互说明

### 7.1 页面说明

- **页面名称**：日历主页
- **入口位置**：URL 直接访问
- **页面元素**：
    - 顶部：年份下拉框、月份下拉框、“回到今天”按钮。
    - 中部：周一至周日的表头。
    - 主体：日期格子区域（仅显示日期数字）。
- **弹窗元素**：日期标题、多行文本输入框（Textarea）、保存按钮、删除/清空按钮、关闭按钮。

### 7.2 交互流程

1. 用户进入页面，系统默认展示当前月份。
2. 用户通过下拉框选择年份/月份，日历实时刷新。
3. 用户点击日期格子，弹出 Modal。
4. 用户在 Textarea 输入内容后点击“保存”，Modal 关闭，格子背景色变色。
5. 用户点击“回到今天”，视图立即跳回当前系统日期所在的月份。

## 8. 文案说明

- **按钮文案**：保存、删除、回到今天。
- **输入框占位符**：请在此输入备忘录内容...
- **异常提示**：若浏览器无痕模式导致无法存储，需在保存时提示“本地存储不可用，数据将无法持久化”。

## 9. 数据与依赖

- **数据依赖**：依赖浏览器原生 `window.localStorage`。
- **逻辑依赖**：依赖原生 JavaScript `Date` 对象进行日期计算。

## 10. 风险与注意事项

- **DOM 性能**：由于不使用框架，需注意在切换月份时高效销毁和重建 DOM 节点。
- **存储限制**：LocalStorage 通常有 5MB 限制，对于纯文本备忘录已足够，但需注意极端情况。
- **兼容性**：需确保在主流 PC 浏览器（Chrome, Edge, Safari）上样式一致。

## 11. 验收标准

- [ ] 日历能正确显示当前月份，且周一排在第一列。
- [ ] 点击有内容的日期，弹窗能正确回显之前保存的文本。
- [ ] 点击保存后，刷新页面，对应日期的背景色标记依然存在。
- [ ] 年份下拉框包含当前年份 -10 到 +10 的选项。
- [ ] 点击“回到今天”能准确跳转回系统当前日期所在的月份。
