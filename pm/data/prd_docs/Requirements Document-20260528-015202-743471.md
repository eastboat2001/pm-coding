## 2. Background and Objectives

### 2.1 Background
The dashboard provides a high-level view of key yield metrics for various factory products. It replaces manual report preparation with automated daily refreshes, allowing QDM and yield teams to monitor performance trends, identify major defect contributors, and attribute losses to responsible departments.

### 2.2 Objectives
*   **Yield Improvement:** Visualize trends to drive a steeper yield improvement curve.
*   **Cost Reduction:** Identify loss drivers to reduce production costs.
*   **Output Optimization:** Increase production output without significant additional investment.
*   **ROI:** Recover investment costs sooner through data-driven quality management.

### 2.3 Success Criteria
*   Business and data owners agree on all metric definitions and source mappings.
*   Users can identify the latest yield, output, and major defects from the primary screen.
*   Drill-down functionality correctly links yield trends to specific defect codes and departments.
*   Dashboard data matches approved source query results within a 0% margin of error.

## 3. Page / Function Presentation

### 3.1 Finished Lot Performance Overview Trend
*   **Purpose:** Display finished yield trends and latest-week performance KPIs.
*   **Header:** `QUALITY OPERATION CENTER - Weekly Finished Lot Performance Overview`.
*   **Main Chart (Left):** A large "Weekly Finished Lot Performance Overview Trend" chart.
    *   **Type:** Bar + Line combo.
    *   **X-Axis:** Time periods (e.g., Week 202612 to 202621).
    *   **Y-Axis:** Yield rate (Line) and Output (Bars).
    *   **Interaction:** Clicking a weekly bar updates the right-side detail panel.
*   **Detail Panel (Right):** KPI cards for the selected week.
    *   **Metrics:** Yield/Target (e.g., 96.83%), Finished Count (e.g., 159 Lots), Output (NSQM), and Loss (NSQM).
    *   **Assumption:** The metric label is assumed to be **NSQM** based on default filter settings, though NSOM appears in some source descriptions.

### 3.2 Loss Ratio By Defect Code
*   **Purpose:** Analyze top defect contributors and their trends.
*   **Main Chart (Left):** "Top 10-20 Loss Ratio By Defect Code".
    *   **Type:** Ranked horizontal bar chart.
    *   **Metrics:** Total Loss Ratio (Red) and Core Loss Ratio (Blue).
    *   **Interaction:** Selecting a defect code updates the right-side trend and attribution charts.
*   **Detail Area (Right):**
    *   **Trend Chart:** Weekly overview trend for the selected defect code.
    *   **Donut Chart:** Department attribution (e.g., Etching + AOI, Assembly, Material).

## 6. Yield Calculation Logic

### 6.1 Definition
Finished Yield (Product Yield) is the product of individual process yields across the full manufacturing path.

### 6.2 Formula
*   **Lot Product Yield:** `(Process1 Output / Process1 Input) × (Process2 Output / Process2 Input) × ... × (ProcessN Output / ProcessN Input)`
*   **Standard Path:** PAOI → E-test → CCAOI → Bump AOI → FVI.
*   **Assumption:** The formula includes "Inline" and "Others" processes if they exist in the lot's approved process path.
