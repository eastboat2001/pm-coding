## 2. 背景与目标

### 2.1 背景
该看板旨在为工厂管理层和工程师提供不同产品关键良率指标的高层视图。通过自动化脚本定时更新（默认按日刷新），减少人工报表制作成本，提升数据实时性。

### 2.2 目标
*   **改善良率：** 通过趋势监控实现更陡峭的良率改善曲线。
*   **降低成本：** 快速识别损失项，降低生产成本。
*   **提升产出：** 在不增加额外投入的情况下优化生产产出。
*   **投资回收：** 加快投资成本的回收速度。

### 2.3 成功标准
*   用户可在首屏快速识别最新成品良率、产出、损失及主要缺陷。
*   支持从总体趋势下钻至缺陷代码（Loss Code）和责任部门。
*   看板数据与已批准的源系统查询结果保持一致。

## 3. 页面 / 功能呈现

### 3.1 Finished Lot Performance Overview Trend (绩效趋势总览)
*   **页面目的：** 展示成品良率随时间的波动趋势，并突出显示最新周的核心 KPI。
*   **核心区域：**
    *   **主趋势图：** 默认按周展示 Finished Yield。支持点击周柱体/数据点切换右侧明细。
    *   **KPI 卡片：** 展示选中周的 Yield/Target、Finished Count、Output (NSQM/NSOM)、Loss。
*   **交互逻辑：** 点击左侧趋势图，右侧明细视图联动更新。

### 3.2 Loss Ratio By Defect Code (缺陷损失占比分析)
*   **页面目的：** 分析导致良率损失的主要缺陷代码及其责任归属。
*   **核心区域：**
    *   **Pareto 排名图：** 展示 Top 10 至 Top 20 的缺陷损失占比（Loss Ratio）及核心损失占比（Core Loss Ratio）。
    *   **缺陷趋势图：** 展示选中缺陷代码的周度趋势对比。
    *   **部门归因图：** 环形图展示责任部门（如 Etching, Assembly 等）的占比。

## 6. 良率计算逻辑

### 6.1 计算公式
成品良率（Finished Yield / Product Yield）采用各关键工序良率的**连乘逻辑**。

*   **单工序良率：** `Process Yield = Output / Input`
*   **成品良率公式：** `Product Yield = Yield(PAOI) × Yield(E-test) × Yield(CCAOI) × Yield(Bump AOI) × Yield(FVI) ...`
*   **周汇总逻辑：** 基于周度总出货量与总投入量的比例进行汇总计算。

## 12. 验收标准 (Acceptance Criteria)

1.  **业务确认：** 业务负责人确认图表清单、指标定义及布局模式。
2.  **数据一致性：** 页面展示数值与 SQL 源查询结果在相同筛选条件下完全一致。
3.  **交互完整性：** 筛选联动、Tooltip 展示、图表下钻功能正常，无死角。
4.  **异常处理：** 空数据状态、加载中状态、API 报错状态均有友好提示。
5.  **响应式验证：** 在 Chrome 和 Edge 浏览器的不同分辨率下无布局错位。
6.  **权限验证：** 导出功能仅对授权角色开放，且导出文件包含筛选上下文。
