# 系统设计文档

## 1. 范围与目标

- **项目名称**: 气象律动 (The Pulsing Prism)
- **需求名称**: 装饰性实时天气与环境监测看板需求文档
- **背景说明**: 打造一个用于客厅或办公室的装饰性 Web 端天气看板，通过极简艺术化的动态几何体展示实时环境数据。
- **目标**: 将抽象的天气数据（温湿度、AQI、风速、紫外线等）转化为具有视觉冲击力的动态艺术作品，兼顾装饰美感与信息查询功能。

### 1.1 本次范围
- Web 端横屏展示。
- 20 个预设精品城市的模拟天气数据展示。
- 10 分钟一轮的艺术化快进动画（8分钟今日演变 + 2分钟预报暗示）。
- 交互式数值信息浮现（点击/悬停）。
- 底部画廊式城市切换。
- 城市记忆功能（恢复上次查看城市）。
- 无人操作 1 小时后的自动轮播模式。

### 1.2 非本次范围
- 全球任意城市实时搜索（仅限预设的 20 个城市）。
- 真实天气 API 接入（初期采用模拟数据）。
- 摄像头人脸靠近检测交互。
- 移动端竖屏适配。

---

## 2. 用户角色与参与方
- **家庭用户**: 将看板作为客厅电视或智能屏的背景装饰。
- **办公人群**: 办公室桌面或公共区域的氛围展示。

---

## 3. 系统用例

### 3.1 用例 1：静默观赏
- **参与者**: 用户
- **触发条件**: 进入页面或切换城市后
- **前置条件**: 页面已加载城市数据
- **主流程**: 
    1. 系统根据当前选定城市加载模拟天气序列。
    2. 启动 10 分钟循环计时器。
    3. 前 8 分钟：几何体根据 24 小时模拟数据进行平滑形态演变。
    4. 后 2 分钟：几何体发生剧烈形态异变（如分裂、坍塌或高频震动）暗示未来预报。
- **验收检查点**: 动画在 10 分钟结束时平滑回到起点或无缝衔接。

### 3.2 用例 2：交互式信息查询
- **参与者**: 用户
- **触发条件**: 鼠标悬停或点击屏幕中心区域
- **前置条件**: 动画正在运行
- **主流程**:
    1. 用户执行交互动作。
    2. 系统计算当前动画进度（0-10分钟）对应的模拟数值。
    3. 在几何体周围浮现文字层：城市名、气温、AQI、风速、紫外线。
    4. 若在最后 2 分钟触发，则显示未来 3 天的数值列表。
- **验收检查点**: 浮现的数值必须与当前几何体的视觉状态（如颜色、转速）逻辑一致。

### 3.3 用例 3：城市切换
- **参与者**: 用户
- **触发条件**: 点击底部画廊缩略图
- **主流程**:
    1. 用户点击缩略图。
    2. 系统获取新城市视觉调优参数。
    3. 几何体通过插值算法，从当前形态平滑过渡到新城市的对应时间点形态。
    4. 更新本地存储的“最后查看城市”。
- **验收检查点**: 切换过程无白屏、无硬切。

## 4. 功能需求

### 4.1 功能明细
- **数字艺术剧场**: 核心渲染引擎，负责将 [温度、风速、AQI、紫外线] 映射为 [颜色、转速、粒子密度、震动频率]。
- **模拟数据生成器**: 后端根据预设城市生成 24 小时 + 3 天预报的伪随机平滑曲线。
- **自动轮播引擎**: 监听用户操作，1 小时静默后按顺序或随机切换城市。

### 4.2 业务规则
- **8:2 比例**: 严格执行 480s (今日) + 120s (预报) 的时间分配。
- **无缝演变**: 城市切换时的插值动画不得少于 2 秒。
- **同步性**: 前端动画帧必须与数据时间轴严格对齐。

---

## 5. 非功能需求
- **性能**: 在主流浏览器（Chrome/Edge）下保持 60FPS。
- **响应式**: 锁定横屏比例（建议 16:9 或 21:9），非目标比例显示黑边。
- **可用性**: 极简 UI，除画廊外无常驻按钮。

---

## 6. 高层架构设计
采用**单体结构**：
- **前端**: 静态 HTML 页面，使用原生 JavaScript + WebGL (或 Three.js) 负责几何体渲染。
- **后端**: C(ASP.NET Core Minimal API) 负责数据分发与配置管理。
- **数据库**: SQLite 嵌入式数据库。

---

## 7. 模块职责划分
- **Web UI 层**: 负责 Canvas 渲染、画廊交互、文字浮层显示。
- **Animation Engine**: 负责数值到几何参数的映射算法（Mapping Logic）。
- **Data Service (C#)**: 提供城市列表、模拟天气序列 API。
- **Storage Provider**: SQLite 读写城市配置与用户偏好。

---

## 8. API 设计（草案）

### 8.1 获取城市列表
- **Endpoint**: `GET /api/cities`
- **Response**: `Array<{ id: int, name: string, thumbnail: string, config: object }>`

### 8.2 获取模拟天气数据
- **Endpoint**: `GET /api/weather/{cityId}`
- **Response**: 
  ```json
  {
    "today_sequence": [{ "time_offset": 0, "temp": 22, "wind": 3, "aqi": 40, "uv": 2 }, ...],
    "forecast": [{ "day": 1, "temp_range": "18-25", "type": "Sunny" }, ...]
  }
  ```

---

## 9. 数据模型与数据库设计

### 9.1 数据库表设计 (SQLite)

#### 表 1: `Cities` (预设城市表)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| CityId | INTEGER | PK, AI | 城市唯一标识 |
| Name | TEXT | NOT NULL | 城市名称（如：北京） |
| VisualParams | TEXT | JSON | **TBD**: 存储手工调优的颜色区间、复杂度等 |
| ThumbnailPath | TEXT | - | 底部画廊用的缩略图路径 |

#### 表 2: `UserPreferences` (用户偏好表)
| 字段名 | 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- |
| Key | TEXT | PK | 配置项名称（如 'last_city_id'） |
| Value | TEXT | - | 配置项值 |

### 9.2 数据约束
- `CityId` 为外键关联。
- `VisualParams` 必须包含 `color_range_start`, `color_range_end`, `rotation_multiplier` 等关键键值。

---

# 10. 关键流程 / 时序说明
1. **初始化**: 前端请求 `/api/cities` 和 `/api/user/preference`。
2. **加载**: 根据 `last_city_id` 请求 `/api/weather/{id}`。
3. **渲染循环**: 
   - `requestAnimationFrame` 驱动 WebGL。
   - 根据 `currentTime % 600s` 计算当前数据切片。
4. **交互**: 监听 `mousemove`，若坐标在中心区，设置 `showOverlay = true`。

---

## 11. 安全、隐私与合规
- **数据隐私**: 仅存储本地城市偏好，不收集用户信息。
- **合规性**: 模拟数据不涉及真实气象预报法律风险。

---

## 12. 可观测性与运维
- **日志**: 后端记录 API 请求耗时。
- **异常**: 前端捕获 WebGL 上下文丢失错误并尝试自动恢复。

---

## 13. 部署与环境规划
- **开发环境**: Visual Studio 2022 + VS Code。
- **部署**: 本地 IIS 托管或轻量级 Kestrel 运行。
- **数据库**: 随程序分发的 `weather.db` 文件。

---

## 14. 测试与验收方案
- **视觉测试**: 验证温度从 0°C 到 40°C 时，几何体颜色是否平滑从蓝变橙。
- **性能测试**: 在 4K 分辨率下运行 1 小时，检查是否有内存泄漏。
- **逻辑测试**: 验证 8 分钟切换到 9 分钟时，文字浮层是否准确切换为预报列表。

---

## 15. 风险、权衡与假设
- **风险**: WebGL 在低端显卡上的表现可能不佳。
- **权衡**: 为了装饰性，牺牲了数据的绝对精确度（采用模拟平滑数据而非跳变的真实数据）。
- **假设**: 假设用户浏览器支持硬件加速。

---

## 16. 里程碑与交付计划
- **W1**: 后端 API 搭建与 SQLite 基础数据填充。
- **W2**: 前端 WebGL 核心几何体映射算法开发。
- **W3**: 交互浮层、画廊 UI 与自动轮播逻辑集成。
