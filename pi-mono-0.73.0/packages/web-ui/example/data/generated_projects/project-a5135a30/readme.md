# 个人备忘录日历

一个基于纯静态网页的个人日历备忘录工具，使用原生 HTML/CSS/JavaScript 开发，无需后端服务器，数据完全存储在用户本地浏览器中。

## 项目特点

- **零依赖**：纯原生技术栈，无需安装任何框架或库
- **隐私安全**：数据完全本地化，不进行任何网络传输
- **即开即用**：直接在浏览器中打开 `index.html` 即可使用
- **轻量级**：文件体积小，加载速度快
- **跨平台**：支持 Chrome、Edge、Safari、Firefox 等主流浏览器

## 功能特性

1. **日历核心展示**
   - 按月展示日期网格，每周从周一开始
   - 支持年份（当前年 ±10年）和月份快速跳转
   - "回到今天"按钮一键返回当前日期视图

2. **备忘录管理**
   - 点击日期格子弹出编辑模态框
   - 支持纯文本备忘录的添加、编辑和删除
   - 自动保存到 LocalStorage，数据持久化

3. **视觉反馈**
   - 有内容的日期显示特殊背景色和标记
   - "今天"日期特殊高亮显示
   - 鼠标悬停效果和动画过渡

## 安装与运行

### 方法一：直接运行（推荐）

1. 下载或克隆项目文件
2. 双击 `index.html` 文件，即可在浏览器中打开
3. 无需安装任何依赖或运行任何命令

### 方法二：使用本地服务器（可选）

如果需要通过本地服务器运行，可以使用以下方式：

```bash
# 使用 Python 内置服务器
python -m http.server 8000

# 或使用 Node.js 的 http-server（需要先安装）
npx http-server

# 或使用 VS Code 的 Live Server 扩展
```

然后在浏览器中访问 `http://localhost:8000`。

## 使用说明

### 基本操作

1. **查看日历**
   - 页面默认显示当前月份的日历
   - 使用顶部的年份和月份下拉框跳转到特定日期

2. **记录备忘**
   - 点击任意日期格子，弹出备忘录编辑框
   - 在文本框中输入备忘内容
   - 点击"保存"按钮，内容将保存到本地存储

3. **管理备忘**
   - 有内容的日期会显示特殊背景色和标记点
   - 再次点击该日期，可以编辑或删除备忘内容
   - 点击"删除"按钮可以清空该日期的备忘录

4. **快速导航**
   - 点击"回到今天"按钮，可以快速返回当前日期所在的月份
   - 使用年份和月份下拉框可以查看历史记录或未来计划

### 数据存储

- 所有备忘录数据都存储在浏览器的 LocalStorage 中
- 数据 Key 格式为：`memo_YYYY-MM-DD`（例如 `memo_2023-10-27`）
- 清除浏览器缓存会导致数据丢失

## 环境要求

- 支持 HTML5 的现代浏览器（Chrome、Edge、Safari、Firefox 最新版本）
- 无需安装 Node.js、npm 或任何其他依赖
- 无需数据库或后端服务器

## 测试与验证

### 功能测试

1. **日历显示测试**
   - 验证日历从周一开始显示
   - 验证每月天数正确（特别是闰年2月）
   - 验证年份下拉框包含当前年 ±10年

2. **备忘录功能测试**
   - 添加备忘内容后，刷新页面，内容应仍然存在
   - 点击有内容的日期，应能正确回显之前保存的文本
   - 删除备忘后，日期格子应恢复默认样式

3. **导航功能测试**
   - 使用下拉框跳转到其他年月，日历应正确刷新
   - 点击"回到今天"按钮，应准确跳转到当前日期

### 性能测试

- 页面加载及日历切换响应时间应小于 100ms
- 在主流浏览器上测试样式一致性

## 已知假设与限制

1. **浏览器兼容性**
   - 假设用户使用的是支持 HTML5 的现代浏览器
   - 未针对旧版浏览器进行优化

2. **数据存储限制**
   - LocalStorage 通常有 5MB 限制，对于纯文本备忘录已足够
   - 清除浏览器缓存会导致数据丢失

3. **响应式设计**
   - 优先保证 PC 端体验，移动端适配有限
   - 未进行深度的移动端响应式优化

4. **功能范围**
   - 仅支持纯文本备忘录，不支持任务清单勾选模式
   - 不支持多端数据同步或导出功能

## 开发说明

### 技术栈

- **前端**：原生 HTML5、CSS3、JavaScript ES6+
- **布局**：CSS Grid、Flexbox
- **存储**：LocalStorage API
- **无框架依赖**：不使用 Vue、React 等框架

### 代码结构

- `index.html`：页面结构和模态框结构
- `style.css`：布局和视觉样式
- `script.js`：业务逻辑、DOM 操作和数据管理

### 模块划分

1. **Calendar Core**：日期计算、生成日期数组
2. **UI Renderer**：根据日期数组生成 HTML 并处理 CSS 类
3. **Storage Manager**：与 LocalStorage 交互
4. **Event Handler**：监听用户操作和事件
